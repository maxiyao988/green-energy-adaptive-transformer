# Historical ETF-holdings SEC source lists

The reconstruction covers **168 fund-quarters** of **ICLN, TAN, QCLN and PBW**,
**2016Q1–2026Q2**. Accession numbers are in `filings_index.csv` and
`parse_log.csv`; `coverage_by_quarter.csv` identifies the selected source for
each fund-quarter. Filings can report holdings on dates other than quarter-end.
This is a descriptive survivorship reconstruction, not a corrected training universe.

| File | Contents | Producer in `revision/research_code/revision_work/scripts/universe/` |
|---|---|---|
| `funds.csv` | Registrant, series and class identities, including the TAN predecessor | `s1_funds.py` |
| `filings_index.csv` | Broader discovered holdings-filing inventory with accessions and EDGAR links | `s1_funds.py` |
| `parse_log.csv` | Holdings filing parsing status, accession, report date and row counts | `s2_holdings.py` |
| `coverage_by_quarter.csv` | Selected filing and obtained status for every fund-quarter | `s2_holdings.py` |
| `survivorship_summary.csv` | Annual constituent and later-exit coverage summary | `s5_summary_report.py` |

`sec13f_lists_parsed.csv` (80 MB; 80,224,192 bytes) is not included. It is
regenerated by `revision_work/scripts/universe/s3a_13f_lists.py`, published at
`revision/research_code/revision_work/scripts/universe/s3a_13f_lists.py`.
`holdings_long.csv`, cached filings and security-level holdings dumps are also
not included. Set `SEC_USER_AGENT` before querying SEC EDGAR. Research scripts
retain their original input/output layout.
