# Step21 protocol — directional accuracy from stored TEST forecasts

Written before Step21 directional-accuracy calculations or hypothesis tests. Existing inputs remain read-only; all outputs are exclusively created within this directory. No training or checkpoint evaluation.

- Table4 scope: all W3 Daily+Weekly cells in the Step16 registry groups core, samepatch, neural and ridge: Single, Fixed, same-patch Fixed, Static, Adaptive, LSTM, Vanilla, SWiM and Ridge, both O/C, h=5/10/20. All five seeds {0,1,21,42,3407}; deterministic Ridge has n=1 and no seed SD. Original neural forecasts use the Step16 B5FIX/B5 uniform 12/12 registry, not archived seed42 forecasts.
- Frozen scope: Step16 primary head-frozen S1/S2, four variants Fixed, Static, Adaptive and constant gate. The complete stored S1 head-retrained sensitivity setting is reported separately, including its explicitly reused Fixed reference; it is not pooled with primary results. No selection by observed performance.
- DA is sum[sign(prediction)==sign(realized)] / count[realized!=0], pooled over TEST stock–date pairs, excluding only exact zeros of realized return. A zero forecast is incorrect for every retained nonzero return. No zero-return tolerance. Compute DA per seed, then the arithmetic five-seed mean and sample SD (ddof=1); do not substitute the sign of the ensemble forecast.
- Validate every prediction's 6,647 TEST keys against the frozen Step16 labels (391 dates,17 stocks); labels must agree in float32 as in Step16, and exact-zero/sign classifications must also agree. Verify registry/canonical/source hashes. References are the stored Step5 Global Train-Mean forecast and the positive-return share, under the same zero exclusion; references are identical for O/C.
- Paired contrasts: Static minus Adaptive for the trained core cells, and Static minus Adaptive plus Adaptive minus constant gate within each frozen backbone/setting/input set. No other contrasts or tests. Positive DA difference favors the first named arm. Report positive/negative/tied seed differences.
- Joint bootstrap: reuse Step16 statistics16_v3 (contiguous float64 matrices), paired seed draws then common non-circular overlapping date blocks, B=20,000,L=h,T=391; seed order [0,1,21,42,3407]. RNG SeedSequence([20261019,h,h,1]); generated indices must equal the stored Step16 draws exactly. No dates are dropped.
- Because exact-zero returns make the valid stock count vary by date, apply the existing imported bootstrap aggregation to (i) each seed/date correct-count difference and (ii) the common valid-count matrix using the SAME draws; divide each sampled numerator by its sampled denominator. This preserves the requested pooled stock–date DA rather than changing the estimand to an unweighted mean of daily DAs. The bootstrap remains paired across arms and seeds.
- Use imported Step5 series_stats for percentile 95% intervals and centered two-sided p with the +1 correction. Use the imported Step16 Holm helper across the three horizons separately for each scope × input set × backbone × frozen setting × contrast. No correction across different backbones, settings, inputs or contrasts; identify every family explicitly. No date-only or seed-level significance tests, and no tests against reference predictors.
- CSV calculations retain full precision; Markdown uses six significant digits. Missing sources or failed integrity checks are BLOCKING, never silently substituted. Record software versions, source hashes, RNG and direct-resampling verification.
